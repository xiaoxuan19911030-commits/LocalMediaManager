## Scope And Safety

v0.7.6 establishes one Provider framework without changing the Standard Merge/Writer contract. It does not add a database migration, deploy to the production installation, execute full-library synchronization, or modify production/user data.

Provider cache, raw-response capture, request history, health state, diagnostics, and benchmark metrics are bounded process-memory state. Playground cannot resolve or invoke `MetadataWriteService`, image writers, or NFO writers.

## Architecture

```text
Existing Provider / future IProviderSdk
                 |
          ProviderCatalog
                 |
          ProviderManager
       /          |          \
Composite     Completion     Playground
Provider      ProviderClient  (read-only)
   |              |               |
Merge/Writer  field filter     raw/result/
(unchanged)   Merge/Writer     merge preview
```

`ProviderCatalog` is the only source for registration metadata, default order, capabilities, minimum delay, and path/media/authentication requirements. Existing `IMetadataProvider` implementations enter through `MetadataProviderSdk`; a future source can implement `IProviderSdk` directly.

## Lifecycle

```text
Capability -> Request -> Search -> Detail/Parser -> ProviderResult -> Merge -> Writer
```

Playground stops at Merge Preview and records Writer as `Skipped`. Standard synchronization continues through the existing fill-empty Merge, image/NFO services, and Writer.

## Playground

Location: Settings -> Developer -> Provider Playground.

Bridge endpoints:

- `GET /api/developer/providers`
- `GET /api/developer/providers/history`
- `POST /api/developer/providers/test`
- `POST /api/developer/providers/cache/clear`

The UI exposes provider state, capabilities, elapsed time, HTTP status when available, parsed field count, cache state, Raw JSON/HTML/XML, ProviderResult, Merge Preview, and stage diagnostics.

## Diagnostics And Failure Categories

Health states: Available, Partial, Offline, AuthenticationRequired, RateLimited, ConfigurationError, ParserBroken, Unsupported.

Failure categories: Network, Timeout, NotFound, RateLimited, Parser, Cloudflare, Authentication, EmptyResult, NoMatch, Configuration, Unsupported, Unknown.

Raw response capture stores response bodies only when Playground supplies a collector. Authorization, Cookie, password, token, and API-key patterns are redacted; request headers are never captured.

## Benchmark And Cache

Benchmark snapshots contain request/success/failure counts, success rate, parser success rate, average elapsed time, last request/success, last error, and failure category. Metrics reset when Bridge exits.

Cache key: `{Provider}:{NormalizedCode}`. Default TTL: 10 minutes. Maximum entries: 256. Manual clear affects only Provider Manager memory and never deletes images, NFO, browser data, or database records. Request history is bounded to 200 entries; each redacted body is truncated to 200,000 characters.

## Mock Provider

Mock is deterministic, offline, and returns a standard `ProviderMetadata` document. It validates registration, SDK resolution, parser/result presentation, Merge Preview, diagnostics, cache, and Writer isolation without a live website.

## Known Limits

- The 50-case parser suite uses deterministic local fixtures and does not prove current live-site availability or anti-bot behavior.
- JavBus currently does not directly parse Plot or Fanart from the fixture page contract.
- MDC-NG remains path/media dependent in its current implementation; v0.7.6 declares that requirement rather than changing Provider behavior.
- Benchmark, cache, diagnostics history, and raw response capture intentionally reset on Bridge restart.
- Human acceptance is still required before deployment or production synchronization.
