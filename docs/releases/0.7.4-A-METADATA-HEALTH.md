## Scope and safety

This phase changes statistics queries, health definitions, physical-file validation, cache invalidation, Dashboard presentation, and automated tests only. It did not synchronize Providers, download images, create NFO files, modify metadata relations or movie numbers, rebuild MediaStorage, move media, or deploy to `D:\Local Media Manager Next`.

The real database check opened `D:\Local Media Manager Next Data\data\LocalMediaManager.db` read-only and enumerated configured MediaStorage without modifying either source.

## Unified definition

The shared authority is `MetadataHealthDefinition`, consumed by `MetadataHealthReader`, `MetadataHealthAnalysisService`, `ProductReader`, Dashboard, metadata filters, and card metadata status.

The Standard denominator requires:

- an enabled `Standard` library;
- a primary `Video` media file;
- `ExistsState` other than `Missing`.

Complete requires all nine conditions:

1. uppercase normalized movie number;
2. title;
3. release date;
4. valid studio relation;
5. valid actor relation;
6. valid `MovieGenres` Provider tag relation;
7. registered Poster whose file exists;
8. registered Fanart whose file exists;
9. an absolute `.nfo` path registered in `Movies.NfoPath` or `NfoDocuments` whose file exists.

`MovieTags` is displayed as user-tag coverage and does not affect completeness. This phase does not change historical Smart Search or tag-navigation compatibility.

## Refresh behavior

- Entering Home requests an explicit fresh health snapshot.
- The refresh icon explicitly invalidates health before reading.
- Successful frontend write operations emit `lmm:data-changed`; health-analysis start/cancel endpoints are excluded so cancellation cannot restart itself.
- Metadata sync completion explicitly invalidates `MetadataHealthAnalysisService`.
- Database, WAL, and SHM timestamp changes invalidate cached results; timestamp removal or rollback is detected with inequality rather than only a newer timestamp.
- Visible Home polls every 30 seconds and refreshes on focus and visibility changes.
- Cache age is capped at 15 minutes.
- Network MediaStorage returns current physical coverage first, marks `resourceInventoryComplete=false`, and performs the full unregistered-resource inventory in the background. The UI displays `统计中` until the inventory is complete.
- Full real NAS inventory took 68.3 seconds; the previously measured quick physical snapshot took about 11 seconds. Dashboard and metadata-health requests use a 30-second client timeout for the quick path.
