# 0.5.0-20 MovieWall Display Optimization Verification

**Date:** 2026-07-18
**Branch:** `sprint/0.5.0-20-moviewall-display`

## Scope

- Optimize MovieWall card density and poster size without creating a second MovieWall.
- Add shared MovieWall display preferences:
  - `portrait` poster: `2:3`
  - `landscape` poster: `16:9`
  - size: `small` / `medium` / `large`
- Persist display preferences through Unified Settings.
- Replace in-flow bottom pagination with a fixed lower-right floating pagination control.
- Add page number input, Enter/Esc behavior, left/right page shortcuts, and Ctrl+G page input focus.
- Keep Smart Search, FilterBar, tag navigation, detail page, scrape logic, image generation logic, and business data unchanged.

## Implementation Notes

- Settings keys:
  - `movieWall.posterOrientation`
  - `movieWall.posterSize`
- Defaults:
  - `portrait`
  - `medium`
- Settings UI location: `设置 → 外观 → 影片墙显示`
- Card mode uses responsive CSS Grid with `auto-fill` / `minmax()`.
- List mode ignores poster orientation and poster size.
- Floating pagination is owned by `MovieWall`, not by `MovieResultContainer`.
