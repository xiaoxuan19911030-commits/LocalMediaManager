# Local Media Manager 0.6.1

发布日期：2026-07-20

## 新功能

- 新增任务类型筛选。
- 新增任务状态筛选。
- 新增批量取消任务。

## UI 优化

- 任务中心顶部重新布局为状态、类型和单一主按钮。
- 主按钮根据当前状态动态显示为清除任务或取消任务。
- 任务列表移除数据库 ID、Task ID 和影片 ID，优先显示番号，没有番号时显示文件名。

## Bug 修复

- 修复同步任务长期停留在等待中的问题。
- 修复任务状态流转异常。
- 修复任务队列消费异常。

## 性能优化

- 优化任务调度唤醒逻辑。
- 优化批量重命名任务的队列执行路径。

## 兼容性

- 兼容 0.6.0 数据库、配置、任务记录和插件目录。
- 未修改数据库 Schema。
- 未修改用户媒体库、评分、收藏、自定义标签或播放记录。

## 升级说明

- 可直接从 0.6.0 覆盖升级。
- 不需要重新扫描。
- 不需要重新同步。
- 旧版本数据库继续兼容。

## 已知问题

- 当前环境未安装 GitHub CLI，自动创建 GitHub Release 需要可用的 GitHub 凭据或手动在 GitHub 页面创建。

## 安装包

- Local Media Manager_0.6.1_x64-setup.exe
