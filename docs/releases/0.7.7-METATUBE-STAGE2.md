## Defect found and fixed

The first isolated run completed all five tasks but only three movies became Metadata Health complete. Two source records used lowercase codes (`abf-120`, `abf-131`). MetaTube returned normalized uppercase codes, but the non-destructive Writer preserved the lowercase stored value.

`MetadataWriteService` now updates a non-empty code only when the stored/task code and Provider code normalize to the same movie number. Different numbers remain protected. The second isolated run verified `abf-120 -> ABF-120` and `abf-131 -> ABF-131` without overwriting manual titles or user data.
