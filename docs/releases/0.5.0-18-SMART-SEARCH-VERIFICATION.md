## Data Semantics

- Movie tags and custom tags both use `Tags/MovieTags`.
- Custom tags are `Tags.Source IN ('User','LegacyStamp')`.
- Movie tags are `Tags.Source NOT IN ('User','LegacyStamp')`, including imported `LegacyLabel`, `NFO`, and scraper sources.
- Genre is separate: `Genres/MovieGenres`; it is not a movie tag.
- Series is `Series/MovieSeries`.
- Directors use `Directors/MovieDirectors` when present; current real DB does not contain these tables.
