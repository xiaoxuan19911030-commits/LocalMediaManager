## Complete Provider Audit

### 777YMYM-030

1. MetaTube Search URL: `http://127.0.0.1:8080/v1/movies/search?q=777YMYM-030&fallback=True`.
2. HTTP: 200. Raw summary: one JAV321 item; `id=777ymym-030`, `number=YMYM-030`, release date `2023-11-28`, and matching title/image URLs.
3. Candidate count/code list: 1, `YMYM-030`. It is an approximate canonical-number candidate but its external ID exactly matches the requested form after case/separator normalization.
4. Original filter: rejected because `AreEquivalent(777YMYM-030, YMYM-030)` was false. Detail did run at `.../v1/movies/JAV321/777ymym-030?lazy=True` and returned HTTP 200, but the result was discarded as `NoMatch`.
5. Fixed behavior: shared matching now also requires and evaluates the Provider external ID. A leading numeric studio segment may be omitted from `number` only when the external ID exactly corroborates the full requested code. No code-specific alias was added.
6. JavBus was called. Original batch requested `https://www.javbus.com/777YMYM-030` (404), then a malformed concatenated mirror URL. Current direct probe returned HTTP 200 but entered `driver-verify`; parser result was empty. The real canonical `YMYM-030` page is evidenced by MetaTube's JavBus candidate, but LMM must not infer that alias from JavBus without corroboration.
7. Final original MetaTube classification: `NoMatch`; final JavBus classification: `NotFound` / later `AuthenticationRequired` or rate-limited depending probe time. Final root cause: **LMM candidate-equivalence bug**, not Provider absence.

### MD-0221

1. MetaTube Search URL: `http://127.0.0.1:8080/v1/movies/search?q=MD-0221&fallback=True`.
2. HTTP: 200. Raw summary: six fuzzy results in the audit (`BMD-221`, `UMD-221`, `KMDS-20221`, `ATMD-221`, `CEMD-221`, duplicate `CEMD-221`).
3. Candidate count/code list: 6. There are approximate candidates, but none is code-equivalent. Composite inspects the first two ranked candidates, runs Detail for `BMD-221` and `UMD-221`, and correctly rejects both.
4. Case, separator, compact form, and zero removal do not produce `MD-0221`; `BMD` and `UMD` are different prefixes and may not be auto-adopted.
5. JavBus was called. Original requests included `https://www.javbus.com/MD-0221`; the configured mirror value was malformed. Current direct probes return HTTP 200 `driver-verify`, so parser output is empty and page existence cannot be established from the body.
6. Final MetaTube classification: `NoMatch`. Final JavBus classification: `AuthenticationRequired` / unusable fallback evidence. Final root cause: **ProviderCoverageGap** for a uniquely recognized Standard-form code. This is not an LMM exact-match defect.

### QQCM-002

1. MetaTube Search URL: `http://127.0.0.1:8080/v1/movies/search?q=QQCM-002&fallback=True`.
2. HTTP: 404 with `{"error":{"code":404,"message":"info not found"}}`; LMM intentionally maps search 404 to an empty result.
3. Candidate count/code list: 0. No approximate candidate, no exact-match filtering, and no Detail request.
4. JavBus was called in the original batch. Direct current request `https://www.javbus.com/QQCM-002` returns HTTP 200 but is a `driver-verify` page; parser result is empty and a real movie page is not established.
5. Final MetaTube classification: `EmptyResult`. Final JavBus classification: `AuthenticationRequired` / no parseable movie. Final root cause: **sample capability mismatch**: the filename itself says domestic short film, outside the present Standard JAV Provider capability.

## Search And Match Logic Review

| Check | Finding |
|---|---|
| Candidate returned but exact match failed | Confirmed for `777YMYM-030`; fixed with external-ID corroboration. Confirmed and correctly retained for `MD-0221`. |
| Case comparison | Case-insensitive throughout tested paths. |
| Hyphen comparison | Separators are normalized for extraction/comparison. |
| Leading zeros | Preserved by canonical normalization. Removing zeros did not recover MD/QQCM. No unsafe zero-equivalence was added. |
| Provider `number` format | MetaTube may return canonical `number` differing from its source `id`; `777ymym-030` / `YMYM-030` is the concrete case. |
| Shared equivalence | Composite, sync Writer gate, Completion client, and Provider Playground now call the same `IMovieNumberExtractor.AreEquivalent(expected, actual, externalId)` rule. |
| Search vs Writer normalizer | Previously both used the extractor for two-argument comparison but lacked external-ID evidence. Both now pass the same evidence. |
| Candidate ranking | MetaTube exact comparable code then Provider preference is retained. MD's first candidates are fuzzy and correctly rejected. |
| First wrong Provider candidate | Composite checks two candidates; both MD candidates were different codes. No false first-candidate adoption occurred. |
| `fallback=True` | Confirmed in actual URLs and by multi-candidate MD responses. |
| JavBus mirror fallback | Existing setting contained multiple URLs joined by a Chinese comma as one syntactically absolute URI, producing a malformed request path. Normalization now rejects values containing an embedded second scheme. |
