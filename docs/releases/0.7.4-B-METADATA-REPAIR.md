## Workflow

The implemented workflow is:

`Scan -> directory snapshot -> shared MetadataHealthSummary -> Dry Run -> plan -> confirmation token -> single transaction -> health refresh -> OperationAudit rollback`

Only active Standard movies are eligible. Local, unassigned, missing-media, low-confidence number, and code re-identification mismatch records are excluded. Existing valid Poster, Fanart, and NFO relations are never replaced.

## Matching rules

| Confidence | Evidence | Automatic action |
|---:|---|---|
| 100 | Exact current video stem or existing path evidence | Eligible after safety checks |
| 90 | Exact normalized number or normalized-number resource directory | Eligible after safety checks |
| 80 | Unique standard resource name in a dedicated movie directory | Eligible after safety checks |
| < 80 | Loose number/name evidence | Manual review only |

Multiple high-confidence singleton candidates and one physical file matching multiple movies are conflicts and cannot execute automatically. The scanner recognizes configured MediaStorage directories, historical resource directories, same-directory resources, and renamed videos whose local image still uses the normalized movie number.
