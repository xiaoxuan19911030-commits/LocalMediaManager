## Notes

- `MovieWall` is now the only page-level user of `MovieResultContainer`.
- Top FilterBar no longer has a tag dropdown.
- FilterBar shows `清空` only when rating, metadata status, image status, or media library differs from page defaults.
- `清空` resets only FilterBar fields and keeps Smart Search plus page defaults such as `favorite=true`.
- Left navigation primary items are: 首页, 影片墙, 媒体库, 标签, 收藏, 最近播放.
- `/tags` is a category page. Its second-level categories are 导演, 标签, 系列, 自定义标签.
- `新加入` and `已收藏` remain status badges only; they are excluded from tag navigation and tag statistics.
- UI keyboard/scroll behavior was implemented in shared React state. Installed verification covered the app/Bridge path; no desktop UI automation runner exists in this repo.
