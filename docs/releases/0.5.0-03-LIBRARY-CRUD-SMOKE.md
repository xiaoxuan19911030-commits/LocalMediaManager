## Scope

- Create and edit media libraries.
- Add, update, and remove source-folder definitions.
- Persist source enablement, subfolder inclusion, scan mode, and exclusion patterns.
- Preview and confirm library deletion with database backup behavior.
- Launch the existing persistent scan workflow without modifying its lifecycle.

## Result

- `dotnet test backend/LocalMediaManager.Bridge.Tests/LocalMediaManager.Bridge.Tests.csproj -c Debug --no-restore`: passed, 33/33 tests.
- `LibraryCrudPersistsMultipleSourcesAndScanRulesForExistingRunner`: passed using two physical source folders and three physical video samples. It created a library, edited both source records and their scan rules, scanned through the existing runner, imported only the two non-excluded video files, and persisted `LastScannedAt` for both folders.
- `LibraryDeleteRequiresPreviewBacksUpAndKeepsMovies`: passed. Delete requires a preview token, creates an operation backup, removes only the library definition, and retains the movie records.
- `pnpm.cmd build:web`: passed.

## Boundaries
