# v0.7.11 Smart Cover Crop

## Root Cause

`MediaCard` rendered every MovieWall cover with `object-fit: cover` and the browser default centered crop. The prior `crop-card` command wrote a new derived image, which cannot satisfy a display-only focus adjustment.

## Design and Data

- `MovieCoverCropSettings` stores one per-movie mode (`AutoFace`, `Left`, `Center`, or `Right`), normalized focus, source-version key, and timestamp.
- The global default is `movieWall.coverCropMode` in the existing unified Settings transaction. Its default is `AutoFace`.
- Manual mode is stored per movie and overrides the global default. Selecting `AutoFace` removes the manual override and resolves cached or newly detected focus.
- No source image is modified and no result is written into an image file.

## Local AI Core

`IAiModel`, `AiModelRegistry`, `AiModelSessionManager`, `AiInferenceQueue`, and `AiResultCache` form the minimal reusable local inference layer. The queue permits two CPU inferences; sessions are owned by the manager; cache data is under `application-data\AI\Cache` and is versioned by cover file metadata plus model version.

YuNet is the first registered model. The `face_detection_yunet_2023mar.onnx` resource is 232,589 bytes, SHA-256 `8F2383E4DD3CFBB4553EA8718107FC0423210DC964F9F4280604804ED2552FA4`, and is distributed with its MIT license notice. It detects face boxes only, selects the largest face, clamps its horizontal center to `0.20..0.80`, and falls back to center on no result or failure.

## UI

`SmartImage` supports CSS `object-position`; `MediaCard` starts centered and requests a focus only after its image loads. The card context menu uses `裁切封面` with `智能识别`, `居左裁切`, `居中裁切`, and `居右裁切`; the active mode is checked. The setting page exposes the global default in the existing MovieWall display section.

## Human Cover Acceptance

1. Open **影片墙** (or **收藏** / **最近播放**), right-click a card, then open **裁切封面**.
2. Select **智能识别**, **居左裁切**, **居中裁切**, or **居右裁切**. The checked item is the active per-movie setting and is saved immediately.
3. For a multiple-face cover, intelligent mode should keep the largest face, not the face closest to the middle. No face or a failed detection must remain centered and visible.
4. If intelligent mode frames the wrong subject, select a manual direction; restart the app and confirm it remains selected. Set the global default in **设置 → 外观 → 影片墙显示 → 封面裁切**.
5. Use only safe images in the test directory for left/right/center/multi-face/no-face and replacement-cache tests. Do not submit those images to Git.

Visual focus correctness, manual persistence after a real restart, cover replacement cache invalidation, and 100-card scroll/performance checks remain pending human acceptance. This report does not claim those visual results passed.
