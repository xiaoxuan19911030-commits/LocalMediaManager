# Local Media Manager 产品愿景

## 产品定位

Local Media Manager（LMM）是一个现代化、本地优先、可扩展的专业媒体管理平台。它以用户拥有并控制的数据为核心，逐步提供元数据管理、媒体库整理、插件、NAS 与受控 AI 能力。

LMM 是独立产品，不再以“Jvedio 改版”为目标。旧 WPF 项目只作为功能、业务规则、数据兼容和回归测试来源，不作为新界面模板。

## 核心价值

1. **本地优先**：核心媒体、元数据与用户状态默认保存在本地，基础浏览不依赖云服务。
2. **用户数据优先**：手工标题、标签、评分、收藏、备注与图片选择高于刮削、插件和 AI 结果。
3. **安全可控**：危险操作先预览影响范围，再确认执行，并提供日志、备份与可行的回滚。
4. **长期可维护**：业务通过 Bridge，数据库通过 Migration，长任务通过 Tasks，页面复用统一组件。
5. **开放扩展**：Provider、插件、NAS 和 AI 都通过明确边界接入，不侵入核心媒体业务。

## 产品原则

- 功能来自实际用户需求与旧版已验证规则；界面使用 LMM 的现代设计体系。
- React 不访问 SQLite、文件系统、系统命令或模型 Provider。
- 所有业务经过 Bridge DTO；所有结构变更经过 Migration。
- 普通搜索、手工管理和本地功能始终独立于 AI。
- AI 默认关闭，只提供建议；未经确认不得覆盖数据或执行危险操作。
- 不以同名入口或只读展示冒充完整功能迁移。

## 目标用户体验

用户应能快速浏览和搜索大规模本地媒体，清楚理解文件与元数据状态，安全完成编辑、扫描、同步、整理与修复，并且随时知道操作正在做什么、影响哪些数据、能否撤销。

## 成功标准

- 1.0.0 前达到核心媒体管理工作流稳定、可诊断、可备份、可升级。
- 主要页面在深浅主题、常见窗口尺寸和 Windows 100%/125%/150% 缩放下保持一致。
- 关键写操作具备自动化测试或可复现验收步骤。
- 版本范围、完成状态和遗留事项可从仓库文档直接确定，不依赖聊天记录。
