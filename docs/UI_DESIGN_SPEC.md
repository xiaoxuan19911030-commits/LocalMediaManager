# Local Media Manager UI Design Specification

## 1. 设计目标

LMM 使用现代、安静、信息清晰的桌面工具视觉语言。所有页面在统一壳层中工作，功能可以持续增加，但不能为单个模块建立另一套配色、间距或控件风格。旧 WPF 页面仅用于理解功能，不作为布局参考。

## 2. 页面框架

- 左侧导航保持统一宽度、图标列、文字列和选中状态。
- 主内容使用统一滚动容器；页面本身不得创建重复的全屏滚动条。
- 页面从 `PageHeader` 开始，包含标题、简短说明和可选主操作。
- 内容区域优先使用 `SurfaceSection`、共享卡片和 MUI Grid/Box 响应式布局。
- 一级导航进入固定产品页面；二级详情使用统一返回按钮返回上级上下文。

## 3. 间距与尺寸

使用 4px 基础网格，常用间距：

| 用途 | 建议值 |
|---|---:|
| 紧密图标/文字 | 4–8px |
| 同组控件 | 8–12px |
| 卡片内部 | 16–20px |
| 区块之间 | 20–24px |
| 页面边距 | 小窗口 16px；常规窗口 24px |

- 交互控件高度保持一致；工具栏优先使用 `small` MUI 控件。
- 圆角由主题统一控制，禁止页面写入相互冲突的任意值。
- 点击目标不小于 36×36px；触屏可用的主要按钮建议不小于 40px 高。

## 4. 字体与信息层级

- 页面标题：MUI `h4`，高字重。
- 区块标题：`h6`，与说明保持明确层级。
- 正文：默认 `body1`；辅助信息使用 `body2`/`caption` 与 `text.secondary`。
- 番号、路径、日期等不可换行字段使用单行省略，并通过 Tooltip 提供完整内容。
- 不用纯颜色表达状态，颜色必须配合文字、图标或形状。

## 5. 颜色与主题

- 所有颜色来自 Material UI theme token，例如 `primary.main`、`text.secondary`、`action.hover` 和 `divider`。
- 禁止为深色模式写死黑色/白色背景；禁止只在单页定义品牌色。
- 状态语义：成功为绿色、警告为橙色、错误为红色、信息为蓝色。
- 深浅主题必须具有相同信息结构、可读对比度和交互状态。

## 6. 控件规范

### 按钮

- 每个区块最多一个主要 `contained` 操作，其余使用 `outlined`、`text` 或菜单。
- 图标必须与功能语义直接相关；仅图标按钮必须提供 Tooltip 和可访问名称。
- 危险操作使用错误色并在执行前显示影响范围和确认。

### 输入与筛选

- 同一工具栏中的输入框、下拉框和按钮高度一致。
- 筛选变化默认回到第一页；清除条件入口必须可见。
- 长筛选栏在窄窗口自动换行，不产生水平滚动。

### Toggle

- Toggle 必须配有明确标签和必要说明，不能仅靠开关位置解释语义。
- 尚未开放的只读配置使用 disabled 状态并说明原因，不模拟保存成功。

### Dialog

- Dialog 标题描述操作对象；正文展示影响范围、不可逆内容和错误恢复方式。
- 取消在左、确认在右；删除等危险确认使用明确动词，不使用含糊“确定”。

### Toast 与错误

- Toast 用于短暂成功/信息反馈；需要用户处理的错误使用页面 Alert 或 Dialog。
- 错误信息说明发生了什么、哪些内容未改变、用户可以如何处理。

## 7. 卡片规范

### 影片卡片

- 固定信息顺序：海报图片、番号、状态标签区域、导入日期、星级评分。
- 番号单行省略；日期显示 `YYYY-MM-DD`；没有标签时保持稳定布局但不显示占位文字。
- `新加入` 使用成功色，`已收藏` 使用错误/强调色；标签不得遮挡番号和日期。
- 普通点击进入详情；播放等 Hover 操作不得阻断触屏和键盘访问。
- 图片使用固定比例和 `object-fit: cover`；原图按需加载，列表使用缩略资源。

### 信息卡片

- 数字、标题和图标对齐；相同区域内卡片高度一致。
- Hover 只提供轻微位移/边框反馈，并尊重 `prefers-reduced-motion`。

## 8. 表格与列表

- 表头固定语义、列宽合理；路径和错误信息允许扩展或 Tooltip。
- 状态、行为、名称、进度和日期按列对齐。
- 空列表使用统一 `EmptyState`，加载使用统一 Circular/Linear Progress。
- 大数据必须分页或虚拟化，不一次渲染全部记录。

## 9. 图标

- 优先使用现有 MUI Icons；同一功能全局使用同一图标。
- 导航图标、操作图标和状态图标职责分开。
- 不使用与行为无关的装饰图标，不用 emoji 替代正式产品图标。

## 10. 响应式与缩放

- 必测 Windows 100%、125%、150% 缩放对应的常用逻辑视口。
- 常规目标视口：1920×1080、1536×864、1280×720；不得出现页面级横向溢出。
- 窄窗口下多列卡片自动减少列数，工具栏换行，长文字省略。
- 最小窗口尺寸以下不承诺完整桌面布局；Tauri 当前最小值是 900×600。

## 11. 可访问性与交互

- 所有可点击卡片支持 Enter/Space；焦点状态可见。
- 纯图标按钮提供可访问名称；表单具有 label。
- 键盘快捷键在文本输入聚焦时不触发页面操作。
- 动画使用短时长并支持系统减少动态效果设置。

## 12. 新页面验收清单

- [ ] 复用 AppShell、PageHeader 和现有公共组件。
- [ ] 深色和浅色主题均通过。
- [ ] 100%/125%/150% 缩放无横向溢出。
- [ ] 加载、空数据、Bridge 错误和部分数据状态齐全。
- [ ] 鼠标、键盘和触屏基本路径可用。
- [ ] 危险操作具备确认、结果提示和回滚边界。
- [ ] 没有页面级 SQLite、文件系统或 Provider 调用。
